# Hospital Analytics Dashboard

This Power BI project was developed as part of the GUVI Hackathon.

## Objective
To analyze hospital operations, including patient admissions, bed utilization, doctor schedules, billing, and outcomes.

## Tools Used
- Power BI Desktop
- CSV datasets
- GitHub

## Features
- Interactive dashboards
- KPI cards
- Conditional formatting
- Slicers for Department, Branch, and Date

## How to Use
1. Download the PBIX file
2. Open in Power BI Desktop
3. Refresh data
4. Explore insights using slicers
